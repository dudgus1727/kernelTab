## 이 표와 A6000 캠페인의 관계

같은 이미지 계열로 **다른 GPU 세대**를 쟀다. 셋은 같고 다섯은 다르다.

| | A6000 (`828baa64`) | **RTX 5090 (`5bb6f403`)** |
|---|---|---|
| 이미지 / CUTLASS | `cu133` / `dcf215af` | **같다** |
| 유저 모드 libcuda | 610.43.02 (forward-compat) | **같다** |
| `nvcc` | 13.3.73 | **같다** |
| GPU | RTX A6000 (sm_86, 84 SM) | **RTX 5090 (sm_120, 170 SM)** |
| 커널 모드 드라이버 | 580.173.02 | **590.48.01** |
| 클럭 (SM / MEM) | 1350 / 7601 | **2392 / 13801** |
| 형상 그리드 | 66 (층 B `M`=1024/128, 층 E 512~8192) | **66 (층 B `M`=4096/2048, 층 E 2048~16384)** |
| `split_k` 축 | 8 종 | **10 종** (5, 7 추가) |

> ⛔ **절대 시간을 직접 비교하지 마라.** `env_hash` 가 다르다는 것이 곧
> 그 뜻이다.

### 전이 실험을 하려면 셋을 맞춰야 한다

```python
df = load_bundles([a6000, rtx5090], common_shapes_only=True)
```

1. **형상** — 층 B 의 `M` 과 층 E 의 사다리가 다르다. 5090 에서 그 형상들이
   런치 오버헤드 아래로 내려가 순위가 안 나왔기 때문이다. 공통은 **53 개**다.
2. **config** — `split_k` 5 와 7 은 A6000 표에 **아예 없다**. 모르고 비교하면
   "5090 에 더 좋은 config 가 있다" 가 규칙 품질 차이로 오독된다.
3. **`is_memory_bound`** — ridge point 가 달라(**A6000 159.1 / 5090 117.9**)
   같은 형상의 분류가 뒤집힌다. 공통 형상 중 **5 개**다:

   ```
   128x4096x4096   128x12288x4096   128x11008x4096
   128x4096x11008  4096x4096x128
   ```

   `BUNDLE.json` 의 `transfer_notes.arith_intensity` 에 형상별 산술 강도가
   있으니, 상대 번들의 ridge 를 대입하면 직접 셀 수 있다.

## 이 표를 읽을 때 알아야 할 것

### `status == "ok"` 로 거르지 마라 — A6000 보다 두 배 버린다

| | A6000 | **RTX 5090** |
|---|---:|---:|
| `high_outlier_frac` | 10.65 % | **22.21 %** |

**결측이 아니라 품질 표시다** — `time_ms` 는 유효하다. 시간 예산 프로토콜
(`target_ms = 20`)이 짧은 커널에 반복을 많이 돌리고, 커널이 빠른 GPU 일수록
IQR 밖 표본이 늘어난다. **거르면 더 빠른 GPU 의 표가 더 얇아 보인다.**

`load_for_ranking()` 의 `ok_only` 기본값은 **`False`** 다 (2026-09-01 변경).
거르려면 명시하고, 두 표에 **같은 기준**을 써라.

### 깊은 클럭 딥 41 행 (0.0032 %)

22.5 시간 중 네 번, 1~2 초씩 SM 클럭이 고정값 아래로 크게 내려갔다
(2370 ~ 2055 MHz). 전력(316~392 W, 상한 600 W)도 온도(58~62 ℃)도 원인이
아닌 순간 이벤트다.

```python
df = df[df.sm_clock_mhz >= 2377]      # 고정값의 -0.63 % 이내
```

나머지 편차는 지원 클럭 **한 칸**(2385 MHz, −0.29 %)이고 전체의 20.8 % 다.
부스트 알고리즘의 입도라 제거할 수 없다.

### 노이즈 계수는 번들에서 읽어라

```
sigma_abs_ms 8e-06   sigma_rel 7.6e-04   tick_ms 1.6e-05
```

`core.noise` 의 모듈 상수(A6000 값)를 쓰면 **틀린다.** `8x4096x4096` 에서
정답 집합이 **1 개**인데 A6000 계수로는 **1,418 개**가 된다.

```python
b = load_bundle("rtx-5090-sm_120-5bb6f403")
ans = b.answer_set(df_one_shape)      # b.coef 를 알아서 넘긴다
```

### 실패 status 0 건

`build_fail` / `runtime_fail` / `oom` / `numerical_fail` /
`below_launch_overhead` / `launch_infeasible` 이 **전부 0 건**이다.
형상 그리드와 축을 측정 전에 SOL 하한으로 검토한 결과다
(`docs/campaign_5090.md`).
